# Introduction to Spring Applications 

* Application Framework : application framework is the set of software fundamenatls foundation for building applications

## Why we used frameworks ?

* Most of the application tasks like caching , security , logging are same in all applications
* Buisiness Logic is the one which changes from one application to another application
* So Frameworks are used to build such applications providing easier time to build it
* Buisiness Logic is tip of iceberg which is the real usecase of this application


* Benefits of fewer chances of introducing bugs
* Reduce time and money
* lot of community members known about it


## Spring ecosystem 
* Spring Core
* Spring Data Access :JDBC and ORM 
* Spring MVC
* Spring testing


## Inversion of control

Normally application controls the dependencies 

Here IOC Container controls and manage the lifecycle of objects for application 

## Spring in Real world scenario
* backend app
* mobile app
* desktop app
* automated testing framework


## When not to use frameworks ?

* Particular functionality with small footprints
* more customised version
* security or defense purposes
* already have a functional app but frameworks give no value
