## Maven Project 

* Maven is the build tool for java
* Build tools is software that use builds apps easily

* Maven helps to download dependecies
* build , run ,debug ,test the application
* validating syntax rules
* security vulnerabilities
* compiling
* packaging the app in archive


* groupId : one which we mention group name for related projects
* artifactId : name of project
* version : identifier in current implementation state


<dependencies> </dependencies> : add dependencies in the project

<dependency> </dependency> : the dependency required for project 

* src : contains java and resources 
* java : contains the application code ; resources contains all the configuration
* test: folder contains for test java files
